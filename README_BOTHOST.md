# Установка Creator Discord Bot на Bothost.ru

## Параметры запуска

- Тип проекта: Discord Bot / Python
- Версия Python: 3.12
- Главный файл: `bot.py`
- Команда запуска: `python -u bot.py`
- Зависимости: автоматически из `requirements.txt`
- Токен: переменная `BOT_TOKEN` (код также понимает `DISCORD_TOKEN`)

## Порядок установки

1. Создай экземпляр Discord Bot на Bothost.
2. Выбери Python 3.12.
3. Загрузи `Creator_Discord_Bot_Bothost.zip` в файловый менеджер проекта и распакуй его.
4. Убедись, что `bot.py` и `requirements.txt` лежат в корневой папке проекта, а не внутри ещё одной вложенной папки.
5. Открой раздел переменных окружения / токена.
6. Добавь токен Discord-бота в `BOT_TOKEN`. Вставляй только сам токен, без кавычек и без `Bot ` в начале.
7. В качестве файла запуска укажи `bot.py`, если панель просит главный файл.
8. Если панель просит команду запуска, укажи `python -u bot.py`.
9. Сохрани настройки, пересобери/перезапусти контейнер и открой консоль логов.

## Что должно быть в корне после распаковки

- `bot.py`
- `requirements.txt`
- `README.md`
- `README_BOTHOST.md`
- `.env.example`
- `data/`

Не загружай настоящий токен в архив и не публикуй его в чате.

## Настройка Discord Developer Portal

1. Открой https://discord.com/developers/applications и создай приложение.
2. В разделе Bot создай бота и скопируй токен.
3. В Bot → Privileged Gateway Intents включи:
   - Server Members Intent
   - Message Content Intent
4. В OAuth2 → URL Generator отметь scopes:
   - `bot`
   - `applications.commands`
5. Выдай необходимые разрешения:
   - View Channels
   - Send Messages
   - Read Message History
   - Embed Links
   - Add Reactions
   - Manage Roles
   - Manage Channels
   - Manage Messages
   - Moderate Members
   - Kick Members
   - Ban Members
   - Move Members
   - Connect
   - Manage Events
6. Открой сгенерированную ссылку и добавь бота на сервер.
7. Перемести роль бота выше тех ролей, которые он должен выдавать или модерировать.

## Первичная настройка на сервере

Команды доступны после запуска. Панели настройки открываются slash-командами:

- `/welcome` — приветствие и роль новичка.
- `/rules` — правила и канал публикации.
- `/roles` — роли и меню выбора.
- `/voice` — голосовой канал-триггер и категория временных комнат.
- `/tickets` — категория тикетов, роль поддержки, канал панели.
- `/logs` — канал журнала.
- `/youtube` — YouTube Channel ID и канал уведомлений.
- `/twitch` — Twitch username и канал уведомлений.
- `/applications` — канал заявок и роль проверяющих.
- `/suggestions` — канал предложений.
- `/faq` — канал и вопросы/ответы.
- `/clips` — канал для клипов.
- `/birthday` — канал поздравлений.
- `/reminders` — напоминания.
- `/automod` — антиспам и фильтр ссылок.

Панели администрирования доступны участникам с правом Manage Server или Administrator.

## Токен и переменные

На Bothost добавь переменную:

`BOT_TOKEN` = токен из Discord Developer Portal.

Для ускоренной синхронизации команд можно добавить:

`GUILD_ID` = ID твоего Discord-сервера.

Для Twitch-уведомлений дополнительно нужны:

`TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`.

Если у хостинга есть отдельное постоянное хранилище, укажи путь к нему через `DB_PATH`, например `/app/data/creator.sqlite3`, и подключи эту папку как постоянную. Если постоянное хранилище не настроено, база может сбрасываться при пересборке контейнера — проверь правила хранения файлов в панели хостинга.

## Проверка запуска

В логах при успешном запуске появится строка примерно такого вида:

`Запущен как ИмяБота (ID)`

Если видишь `Токен не найден`, проверь переменную `BOT_TOKEN`.
Если видишь `401 Unauthorized` или `Improper token has been passed`, токен неверный: создай новый в Developer Portal и обнови переменную.
Если видишь `PrivilegedIntentsRequired`, включи оба Privileged Gateway Intents в Developer Portal.
Если команды не появились сразу, проверь `GUILD_ID`, scopes `applications.commands` и перезапусти бота.

## Безопасность

Никому не отправляй токен. Не добавляй `.env` с настоящим токеном в архив. Если токен попал к посторонним, сбрось его в Discord Developer Portal.


## Отдельная панель заявок на роли

Создай роли:
- `🆕 Новичок` — бот выдаёт автоматически по кнопке.
- `👤 Зритель` — выдаётся после проверки скриншота подписки.
- `⏳ На проверке` — необязательная временная роль на время рассмотрения.

Создай категорию `📩 ЗАЯВКИ НА РОЛИ`. В ней бот создаёт приватный канал для каждого участника. Настрой права категории так, чтобы обычные участники не могли просматривать чужие заявки; сам бот, заявитель и роль проверяющих получат доступ к конкретной заявке.

Далее в Discord:

1. Введи `/role_requests`.
2. Нажми **Настроить каналы** и вставь ID:
   - публичного канала, где будет кнопочная панель;
   - категории приватных заявок;
   - роли администрации / проверяющих.
3. Нажми **Настроить роли** и вставь ID:
   - роли `Новичок`;
   - роли `Зритель`;
   - роли `На проверке` (можно оставить пустым).
4. Нажми **Опубликовать панель**.

На панели появятся кнопки:
- `Получить роль «Новичок»` — бот выдаст её сразу.
- `Зритель YouTube` — создаст приватную заявку и попросит скриншот подписки на YouTube.
- `Зритель Twitch` — создаст приватную заявку и попросит скриншот подписки на Twitch.

Когда участник отправит изображение в свой приватный канал, бот добавит сообщение с доказательством и кнопками **Одобрить / Отклонить**. Кнопки доступны только администратору или роли проверяющих. После одобрения бот выдаёт «Зритель» и снимает «На проверке»; после отказа снимает «На проверке» и уведомляет участника.

Проверка подписки по изображению выполняется человеком: скриншот — доказательство для ручной проверки, а не автоматическое подтверждение факта подписки. У роли бота должны быть `Manage Channels`, `Manage Roles`, `Send Messages`, `View Channels`, `Read Message History` и `Embed Links`. Роль бота должна находиться выше трёх настраиваемых ролей.


После обновления дизайна снова нажми `/role_requests` → **Опубликовать панель**. Новое сообщение появится в выбранном канале; старое сообщение нужно удалить вручную.


## Что происходит после решения по заявке

После нажатия администрацией кнопки «Одобрить» или «Отклонить» бот:
- отправляет участнику красивое личное сообщение с результатом;
- указывает платформу и имя администратора, который рассмотрел заявку;
- при одобрении выдаёт роль «Зритель» и снимает «На проверке»;
- при отказе снимает «На проверке»;
- записывает результат в журнал действий;
- через 5 секунд автоматически удаляет приватный канал заявки.

Если у участника закрыты личные сообщения, бот зафиксирует это в журнале, но не сможет доставить уведомление. Для удаления приватного канала боту требуется право `Manage Channels`.
